# OWL Studio

Автор оригинала: [Xonars](https://github.com/Xonars/dev.omalauncher-widgets-another).

Локальная разработка Xonars.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: MIT. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/xonars-owl-studio-v01/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
