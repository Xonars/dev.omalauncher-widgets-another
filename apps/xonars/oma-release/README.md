# OMA · релиз

Автор оригинала: [Xonars](https://github.com/Xonars/dev.omalauncher-widgets-another).

Первая версия — проверка готовности выпуска без изменения репозитория и без доступа к приватному ключу. Используется существующая локальная авторизация gh. Проверяется точный HEAD main, успешный push CI, номер последнего стабильного Build и единственный неистёкший артефакт. Никакая сборка или установка не запускается автоматически.

## Выпуск вручную

1. Нажать «Проверить сборку». Если Build уже опубликован, сначала требуется новый versionCode и успешный CI.
2. Скопировать команду скачивания, выполнить в терминале. Она сверяет SHA-256 ZIP.
3. В этом каталоге подписать app-foss-debug.apk локальным оригинальным debug.keystore через Android Build Tools 37.0.0 apksigner. Указать PKCS12 и alias androiddebugkey. Вводить пароль только локально.
4. Проверить готовый APK через scripts/verify-apk.py из точного коммита сборки. Не заменять ожидаемый сертификат. Проверить соответствие versionCode, applicationId и ARM64-библиотек.
5. В GitHub Releases создать черновик с указанным в приложении тегом и target, соответствующим проверенному HEAD. Добавить один APK OMA-Another-N.apk. Сверить размер и SHA-256 загруженного APK, затем опубликовать стабильный релиз.
6. Открыть OMA Update и установить обновление.

Приложение не выполняет подпись и публикацию само. Не хранит пароли, токены или ключи. Для выпуска используется существующий ключ, не временный ключ CI.
