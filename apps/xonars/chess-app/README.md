# Шахматы

OWL-приложение Xonars на основе виджета vitalii-khomenko.
Исходный виджет: https://github.com/SimonSchubert/omarchy-widgets/tree/main/widgets/vitalii-khomenko/chess

Оригинальное авторство и лицензия исходника сохраняются. Это производная работа, включённая в коллекцию по указанию Xonars.

Локальные исходники и зависимости: [local/README.md](../../../local/README.md).
