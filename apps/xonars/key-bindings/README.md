# Key Bindings

Автор оригинала: [Xonars](https://github.com/Xonars/dev.omalauncher-widgets-another).

Локальная разработка; сведения об исходных компонентах и лицензиях сохранены в файлах.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: Не указана в OWL; см. исходники и зависимости. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/xonars-key-bindings/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
