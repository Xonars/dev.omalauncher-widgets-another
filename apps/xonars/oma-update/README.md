# OMA · обновление

Автор оригинала: [Xonars](https://github.com/Xonars/dev.omalauncher-widgets-another).

Локальная разработка; сведения об исходных компонентах и лицензиях сохранены в файлах.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: Не указана в OWL; см. исходники и зависимости. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/xonars-oma-update/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.

Обновлятор предназначен для конфигурации OMA Another с репозиторием `~/dev.omalauncher-another`; ключ подписи и SDK не входят в магазин.

## GitHub Releases (1.1.1)

На главной странице есть отдельный сценарий: проверить стабильный релиз → скачать APK → установить через `omalauncher-install`. Репозиторий закрыт: используются уже настроенные `gh auth login`, Git credential helper или переменные GH_TOKEN/GITHUB_TOKEN. Секреты не сохраняются в приложении и не передаются серверу загрузки при перенаправлении. Требуется один опубликованный APK с именем `OMA-Another-*.apk` или `omalauncher-another-*.apk` (также `app-foss-debug.apk` или `app-debug.apk`) и SHA-256 от GitHub. CI APK с другим сертификатом отклоняется. Проверка использует существующие Android Build Tools 37.0.0 (aapt2/apksigner), без Gradle, JDK сборки, NDK или checkout. Обновление только на больший versionCode. Локальная сборка остаётся отдельным сценарием.
