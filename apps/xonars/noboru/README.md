# Noboru · Манга

Автор оригинала: [Xonars](https://github.com/Xonars/dev.omalauncher-widgets-another).

Локальная разработка; сведения об исходных компонентах и лицензиях сохранены в файлах.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: MIT. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/xonars-noboru/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
