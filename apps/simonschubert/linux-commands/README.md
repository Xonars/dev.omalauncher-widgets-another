# linux commands

Автор оригинала: [simonschubert](https://github.com/SimonSchubert/omarchy-widgets/tree/main/apps/simonschubert/linux-commands).

Оригинал simonschubert; локальная версия Xonars. Наличие отличий само по себе не подтверждает авторство каждого изменения.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: Apache-2.0. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/simonschubert-linux-commands/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
