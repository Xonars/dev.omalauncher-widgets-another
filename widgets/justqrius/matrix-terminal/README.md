# matrix terminal

Автор оригинала: [justqrius](https://github.com/SimonSchubert/omarchy-widgets/tree/main/widgets/justqrius/matrix-terminal).

Оригинал justqrius; локальная версия Xonars. Наличие отличий само по себе не подтверждает авторство каждого изменения.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: MIT. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/justqrius-matrix-terminal/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
