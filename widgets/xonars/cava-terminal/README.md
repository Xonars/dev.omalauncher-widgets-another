# cava terminal

Автор оригинала: [Xonars; терминальные компоненты tmux/cava](https://github.com/SimonSchubert/omalauncher).

Локальная конфигурация; оригинальные комментарии сохранены.

Локальная упаковка и сопровождение: Xonars. Исходная лицензия: MIT. Уведомления о лицензиях в исходниках и ресурсах сохранены.

При первом запуске скачивается пакет ресурсов с этого магазина, проверяется SHA-256 и устанавливается в собственный каталог `~/.local/share/omalauncher-store/xonars-cava-terminal/`. Требуется сеть; установленные ресурсы доступны офлайн. Личные файлы и исходные помощники телефона не перезаписываются.
