# Локальная коллекция OWL

Снимок приложений и виджетов с телефона от 28.10.2026. Основа репозитория — SimonSchubert/omarchy-widgets, ветка main.

- `widgets/`: все активные локальные OWL-файлы, документация и вспомогательные каталоги.
- `archive/`: ранее убранные OWL-файлы; не устанавливаются автоматически.
- `support/`: вспомогательные исходники, которые находились вне каталога виджетов.
- `catalog.json`: имена, типы и пути активных OWL-файлов.
- `sha256.json`: контрольные суммы сохранённых исходников.
- `../apps/xonars/`: отдельные записи локальных приложений для каталога.

Сторонние приложения и локальные адаптации сохраняют оригинальные метаданные, комментарии авторства и лицензии. Наличие файла здесь не означает, что его автор — Xonars или что он прошёл проверку публичного магазина.

## Восстановление

Выборочно скопируйте нужные OWL-файлы и одноимённые каталоги из `widgets/` в `~/.config/omalauncher/widgets/`. Существующие файлы сначала сохраните. Приложения появятся в меню лаунчера. Проверка: `owl-check ~/.config/omalauncher/widgets/<имя>.owl`.

Дополнительные зависимости:

- OMA Update: файлы из `support/oma-updater/` ожидаются в `~/.local/share/oma-updater/`; нужны локальные исходники лаунчера, SDK и ключ подписи. Скрипт сохраняет исходную настройку обновления upstream, а не нового проекта Another.
- APK Maker: `support/apk-maker/{bin,template,skills}` и файлы версии — исходники установленного комплекта. Рабочая установка использует структуру релизов/current; для первичной настройки предпочтителен встроенный установщик приложения. SDK, ключи и настройки аккаунтов сюда не включены.
- Tweaks: `support/omalauncher-tweaks/tweaks.py` ожидается в `~/.cache/omalauncher-tweaks/`.
- Reader: каталог из `support/owl-reader-store/` ожидается в `~/.local/share/owl-reader-store/`.
- Pinterest wallswap содержит исходник `login-window.cpp` и локальный бинарный файл `login-window`; пересоберите для другой архитектуры.

Это сохранение исходников: пользовательские сессии, cookies, кэши, SDK, ключи подписи, книги и загруженные изображения не переносились. Абсолютные пути `/root` в исходниках сохранены; на другой системе их нужно адаптировать. Секреты для CI и публикация GitHub Pages не настроены.
