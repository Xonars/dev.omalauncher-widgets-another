# Локальные исходники Xonars

Здесь сохранены исходники приложений из `../apps/xonars/`, виджет аккумулятора и необходимые вспомогательные файлы. Состав подтверждён Xonars: пять оригинальных приложений и две производные работы (Шахматы и APK Maker). В catalog.json они помечены как xonars/original и xonars/derived.

Сторонние приложения, не включённые владельцем адаптации, панели и keybar исключены из этой коллекции. Полный снимок до разделения сохранён в `/root/OMA-RESTORE/store-sources-20261030-120549/collection`.

`catalog.json` перечисляет исходные точки входа, `sha256.json` — контрольные суммы. Это коллекция исходников, а не готовый установщик: некоторые приложения требуют каталогов ресурсов из `widgets/` и внешних helper-скриптов. GitHub Store пока устанавливает только OWL, без этих каталогов.

Установленные файлы телефона не изменялись. Источник GitHub Pages требует отдельной публикации.
