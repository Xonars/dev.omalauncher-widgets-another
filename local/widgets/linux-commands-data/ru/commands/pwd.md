# TAGLINE
Вывести название текущего/рабочего каталога. Больше информации: <https://www.gnu.org/software/coreutils/manual/html_node/pwd-invocation.html>.
# TLDR


- Вывести текущий каталог:

```
pwd
```

- Вывести текущий каталог, разрешая все символические ссылки (т.е. показать "физический" путь):

```
pwd {{[-P|--physical]}}
```

- Отобразить помощь:

```
pwd --help
```
