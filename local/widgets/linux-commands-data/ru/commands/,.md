# TAGLINE
Запускать команды без их установки. Больше информации: <https://github.com/nix-community/comma>.
# TLDR


- Запустить команду:

```
, {{команда -с -флагами}}
```

- Добавить команду в дочернюю оболочку:

```
, {{[-s|--shell]}} {{команда}}
```

- Очистить кэш:

```
, {{[-e|--empty-cache]}}
```
