# TAGLINE
Создавать файл системного ключа в каталоге конфигурации Elasticsearch. Больше информации: <https://www.elastic.co/docs/reference/elasticsearch/command-line-tools/syskeygen>.
# TLDR


- Сгенерировать файл `system_key` в каталоге `$ES_HOME/config` по умолчанию:

```
elasticsearch-syskeygen
```
