# TAGLINE
Проверять, доступно ли название пакета или организации в npm. Больше информации: <https://github.com/sindresorhus/npm-name-cli>.
# TLDR


- Проверить, доступно ли конкретное название пакета в реестре `npm`:

```
npm-name {{пакет}}
```

- Найти подобные названия пакетов в реестре `npm`:

```
npm-name --similar {{пакет}}
```
