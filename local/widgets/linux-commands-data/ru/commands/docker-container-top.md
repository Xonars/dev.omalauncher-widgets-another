# TAGLINE
Отображать запущенные процессы контейнера. Больше информации: <https://docs.docker.com/reference/cli/docker/container/top/>.
# TLDR


- Отобразить запущенные процессы контейнера:

```
docker {{[top|container top]}} {{контейнер}}
```

- Показать справку:

```
docker {{[top|container top]}} --help
```
