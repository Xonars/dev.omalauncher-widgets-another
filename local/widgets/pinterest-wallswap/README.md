# Pinterest wallswap

Приложение `../pinterest-wallswap.owl`, основанное на wallswap (petrzpav, MIT).

При открытии сразу показывается каталог публичных досок отслеживаемых
профилей Pinterest. Нажмите на доску: откроется просмотр изображений только
этой доски и автоматически загрузится первое фото. «Далее» и «Назад» листают
изображения внутри открытой доски. Нажатие на фото включает полноэкранный
просмотр, кнопка «Пин» открывает источник в Pinterest.

Кнопка «Доски» и системная кнопка назад возвращают в каталог; в полноэкранном
режиме назад сначала возвращает к обычному просмотру доски.
При переходе на другую доску история и запас изображений сбрасываются.
Пока доска открыта, заранее загружаются четыре изображения только из неё.
В каталоге загрузка изображений не запускается.

В каталоге есть поиск, страницы по 40 досок и ручное обновление списка.
Профили задаются в настройках именами через запятую. По умолчанию — xonars.
Список досок обновляется раз в шесть часов. Закрытые доски без входа
недоступны. Изменение внутренних ресурсов Pinterest может нарушить загрузку;
ошибка показывается в приложении.

Изображения скачиваются с i.pinimg.com в ~/.cache/pinterest-wallswap/.
Пины открытой доски догружаются с пагинацией до 1000 штук.
Приложение не изменяет обои.

Проверено: owl-check и PNG начального экрана; автоматическое начало загрузки,
сброс очереди и истории при переходе между досками, листание внутри доски
и отсутствие запуска загрузки из каталога (изолированная проверка backend).

## Загрузка досок и сохранённые копии

В настройках есть «Директория сохранения», по умолчанию `~/Pictures`.
Доступность папки проверяется при сохранении. Файлы каждой доски находятся
в `Pinterest/<профиль>/<имя-доски>-<id>/` внутри выбранной директории.
Изменение настройки не перемещает прежние загрузки: они остаются доступны.

Откройте доску и нажмите «Загрузить всё». В окне «Загрузки» показываются
очередь, число сохранённых изображений, прогресс и ошибки. Примерный итог
во время скачивания берётся из счётчика пинов, который может отличаться от
числа изображений. По завершении показывается фактическое число файлов.
Загрузки выполняются по одной и продолжаются после закрытия приложения.
«Повторить» возобновляет неудавшуюся загрузку; имеющиеся файлы пропускаются.
«Обновить» проверяет доску на новые изображения.

Карточки досок помечены «Не скачано», «Загрузка», «Частично» или «Скачано».
Готовые доски выделены зелёным. Сохранённые изображения показываются
непосредственно из выбранной папки без сети, включая листание и полноэкранный
просмотр. Частично скачанная доска также показывает имеющуюся локальную копию.
Метаданные и индекс находятся рядом с изображениями; список задач —
`~/.local/state/pinterest-wallswap/downloads.json`.

Используется gallery-dl 1.32.18 в отдельном окружении:
`~/.local/share/pinterest-wallswap/venv/bin/gallery-dl`.
Если его нет, используется `gallery-dl` из PATH. Для установки на другой системе:

```
python -m venv --system-site-packages ~/.local/share/pinterest-wallswap/venv
~/.local/share/pinterest-wallswap/venv/bin/python -m pip install gallery-dl
```

Параметры CLI: https://gdl-org.github.io/docs/options.html.
Скачиваются изображения; видео исключаются из загрузки.

Проверено на реальной доске Kalimba: скачаны два изображения, повторная
загрузка пропустила имеющиеся файлы. Проверено локальное листание без
сетевого загрузчика. Шесть изолированных тестов проверяют очередь,
повторную загрузку, частичный сбой, исчезнувшие файлы, валидацию путей
и просмотр без сети:

```
python -m unittest discover -s ~/.config/omalauncher/widgets/pinterest-wallswap -p test_downloads.py -v
```

## Лента, вход и сохранение пинов

На главном экране рядом с обновлением и загрузкой досок есть «Лента».
Для персональной ленты и сохранения пинов выполните прямой вход Pinterest
из настроек или экрана ленты: «Войти по email». Введите email своего аккаунта
и пароль Pinterest на настоящей странице https://www.pinterest.com/login/.
Если отдельного пароля Pinterest нет, кнопка «Задать пароль Pinterest»
открывает https://www.pinterest.com/password/reset/. Восстановление через
почту выполняет владелец аккаунта на странице Pinterest. Приложение само
не отправляет письма и не меняет пароль.

Вход через Google из этого управляемого окна отклонён Google с ошибкой
“This browser or app may not be secure”. Открытие формы Google не доказывало
возможность авторизации: прежний тест проверял только её загрузку. Кнопка
Google удалена из приложения; старый аргумент `--google` теперь открывает
обычный вход Pinterest, а не повторяет заблокированный вход. User-Agent
или признаки управляемого браузера для обхода этой проверки не маскируются.

Используется отдельный временный профиль Chromium с отключённым сохранением
паролей. Приложению передаются только cookies Pinterest. Сессия приложения
хранится в `~/.local/state/pinterest-wallswap/` (700), файлы сессии имеют права
600. Пароли не читаются приложением и не попадают в OWL или вывод проверок.
Связь с браузером идёт через приватные унаследованные каналы без открытого
TCP-порта. «Выйти» удаляет сессию приложения.

Запуск — `~/.local/bin/pinterest-login`; для восстановления пароля используется
`--reset-password`. Требуются Chromium и Node.js. Старое окно Qt
(`login-window.cpp`) больше не используется.

Официальные инструкции:
- https://support.google.com/accounts/answer/7675428
- https://help.pinterest.com/en/article/log-in-and-out-of-pinterest
- https://help.pinterest.com/en/article/reset-your-password

Лента показывает до 20 изображений на странице онлайн. Нажмите изображение
для просмотра крупнее, затем «Сохранить на доску»; на карточке ленты есть
короткая кнопка «На доску». В окне выбора показаны свои доски подключённого
аккаунта и доступные совместные доски, с поиском и страницами. Сохранение
выполняется только по нажатию на конкретную доску. Можно сохранить разные
пины на разные доски и один пин на несколько досок. После подтверждения
Pinterest сохраняется отметка об успешном действии. Сетевые ошибки при
записи не повторяются автоматически.

Доска с новыми пинами или неполной копией выделяется оранжевым и пометкой
«Нужно докачать». Изменения отслеживаются по дате изменения доски и успешным
сохранениям из ленты. После внешних изменений нажмите «Обновить доски».
Кнопка «Обновить копию» внутри доски или «Обновить» в загрузках запускает
докачку. Пины, добавленные во время скачивания, сохраняют оранжевую отметку
до следующего обновления. Все прежние изображения остаются в папке и индексе,
даже если их удалили из Pinterest. Повторная загрузка не выполняет зеркальное
удаление файлов.

gallery-dl автоматически использует подключённую сессию. Без входа Pinterest
может выдавать только часть пинов; такая копия помечается как неполная.
`gallery_runner.py` поддерживает два формата bookmarks Pinterest, не изменяя
установленную библиотеку gallery-dl.

Проверено: загрузка форм входа, PNG формы и главного экрана, owl-check; 17 тестов
временных данных для очереди, сохранения, прав на доски, пагинации,
оранжевых отметок, сохранности удалённых онлайн пинов и просмотра без сети.
Работу персональной ленты и реальную запись пина нужно подтвердить после
входа владельца аккаунта; без его авторизации эти операции не выполнялись.

Проверки нового окна входа:

```
node --test login-browser.test.mjs
node login-browser.mjs --self-test-login
node login-browser.mjs --self-test-reset
```

Формы проверяются с новым временным профилем, без ввода учётных данных.
Пять тестов проверяют фильтрацию cookies, срок действия сессии, обработку
приватного канала при фрагментированных ответах и закрытии окна, а также
отсутствие перенаправления к Google по старому аргументу.
Сам вход в аккаунт выполняет владелец; успешная загрузка формы не является
проверкой успешной авторизации.
