# APK Share

Откройте APK Share, нажмите Install у нужного APK и подтвердите установку в Android.
Кнопка Install вызывает omalauncher-install с полным путём к APK; HTTP-сервер для неё не нужен.
Для скачивания нажмите Start, затем Download у нужного APK.
Можно открыть http://127.0.0.1:8765/ в браузере Android.
Скачайте APK и откройте его для установки через Android.
Каталог по умолчанию ~/APK, адрес 127.0.0.1, порт 8765.
Сервер выдаёт только APK, не следует симлинкам и работает пока запущен Linux.
