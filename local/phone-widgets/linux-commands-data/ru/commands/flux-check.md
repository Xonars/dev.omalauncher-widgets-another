# TAGLINE
Проверять предварительные требования Flux и состояние кластера. Больше информации: <https://fluxcd.io/flux/cmd/flux_check/>.
# TLDR


- Проверить предварительные требования перед установкой Flux:

```
flux check --pre
```

- Проверить состояние и работоспособность всех контроллеров Flux:

```
flux check
```
