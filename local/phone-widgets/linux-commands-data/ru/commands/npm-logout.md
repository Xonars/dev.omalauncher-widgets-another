# TAGLINE
Выходить из учётной записи пользователя реестра. Смотрите также: `npm login`. Больше информации: <https://docs.npmjs.com/cli/npm-logout/>.
# TLDR


- Выйти из учётной записи пользователя реестра:

```
npm logout
```

- Выйти с использованием пользовательского реестра:

```
npm logout --registry {{url_реестра}}
```
