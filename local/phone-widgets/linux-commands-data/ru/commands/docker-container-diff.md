# TAGLINE
Проверять изменения файлов или каталогов в файловой системе контейнера. Больше информации: <https://docs.docker.com/reference/cli/docker/container/diff/>.
# TLDR


- Проверить изменения в контейнере с момента его создания:

```
docker {{[diff|container diff]}} {{контейнер}}
```

- Показать справку:

```
docker {{[diff|container diff]}} --help
```
