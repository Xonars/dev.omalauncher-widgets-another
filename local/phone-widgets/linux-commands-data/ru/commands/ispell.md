# TAGLINE
Интерактивная проверка орфографии. Больше информации: <https://www.cs.hmc.edu/~geoff/ispell-man.html>.
# TLDR


- Начать интерактивную сессию:

```
ispell
```

- Проверить на ошибки указанный файл и интерактивно применить исправления:

```
ispell {{путь/к/файлу}}
```

- Отобразить версию:

```
ispell -v
```
