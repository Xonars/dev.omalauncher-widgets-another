# Noboru 2.0 — манга на русском

Основной сценарий: найти русский перевод → открыть главы → читать или скачать → открыть во вкладке «Офлайн».

Поиск одновременно обращается к ReManga, Dreamy Manga, Манговой, MangaHub RU, MangaChan и MangaDex (только язык ru).
Ответы объединяются, сбой одного источника не скрывает остальные. Карточки ReManga с явно нулевым числом глав исключаются.
Разные переводы остаются отдельными карточками с названием источника. Из пустой карточки можно запустить поиск других переводов.
ReadManga поддерживается для ранее добавленных карточек, но исключена из общего поиска из-за проблем с сервером изображений.
Главы Dreamy Manga читаются и скачиваются в Noboru. Манговая запрещает сторонним читалкам загружать страницы, поэтому её главы открываются на сайте.

На странице манги показаны все ветки перевода, поиск по главам и страницы по 80 записей.
Кнопка ↓ скачивает главу, ✓ означает готовую офлайн-копию. «Скачать все главы офлайн» последовательно скачивает доступные главы в фоне.
Платные главы ReManga без покупки и внешние главы MangaDex открываются на сайте и не включаются в массовую загрузку.
Вкладка «Офлайн» показывает прогресс, ошибки с кнопкой повтора и полностью скачанные главы.
Список глав сохраняется: при ошибке сети показывается кэш с соответствующей подписью.
Читалка поддерживает страницы, масштаб, Webtoon, полный экран и сохранение позиции.

Данные: ~/.local/share/noboru-owl/. Готовые главы содержат страницы, метаданные и chapter.cbz.
Глава появляется в офлайн-библиотеке после успешного скачивания всех страниц и создания архива.
Повторная загрузка использует уже скачанные страницы. Для чтения завершённой загрузки сеть не нужна.
Фоновые загрузки требуют работающего Linux. Доступность отдельных сайтов зависит от сети и самих источников.

Зависимости перечислены в noboru.owl: python, python-pillow, python-beautifulsoup4.
Проверки: python -m unittest discover -s noboru -p 'test*.py'; owl-check noboru.owl.
