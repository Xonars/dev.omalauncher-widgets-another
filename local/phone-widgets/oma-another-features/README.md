# Oma Another Features

Пользовательский каталог отличий OMA Another от Oma Launcher.

Файлы интерфейса рядом с этой папкой:
- 84-oma-another-features-app.owl — приложение в списке приложений.
- 85-oma-another-features.owl — виджет 3×2; по нажатию открывает приложение.
- catalog.json — единые данные для приложения и счётчика виджета.

Каталог — редакционная подборка, а не автоматически вычисляемый полный diff. Одна карточка — одна пользовательская возможность; связанные настройки могут быть объединены. Сейчас сравниваются локальные исходники cabce989b396f47bc17214ea780c93ecf0ef72a1 и upstream 4d2cf3f22041b14bb0db76c72131c40e78076d80. Это проверка реализации в коде, не испытание установленного APK на оборудовании.

## Как добавить возможность

Добавьте объект в features в catalog.json:
- id: уникальный постоянный идентификатор;
- category: Экран / Управление / Данные / Медиа / Приложения;
- title: название понятное пользователю;
- summary: краткая польза;
- details: подробное описание без внутренней архитектуры;
- howTo: как открыть и использовать;
- limitations: разрешения, требования и ограничения;
- screenshots: массив изображений, пока может быть пустым;
- evidence: относительные пути исходников, подтверждающие отличие.

Счётчик вычисляется через len(features) в обоих интерфейсах; отдельное число править не нужно. Не включайте общие с Oma Launcher функции и запланированные возможности. После повторного сравнения обновляйте reviewed, sourceCommit и upstreamCommit. Избранное хранится отдельно как persist-состояние приложения.

## Скриншоты

Создайте внутри этой папки screenshots/ и добавьте настоящие PNG или WebP. В карточку добавьте, например:

    "screenshots": [
      {
        "src": "~/.config/omalauncher/widgets/oma-another-features/screenshots/oma-input.png",
        "caption": "Русская клавиатура OMA Input с дополнительными клавишами"
      }
    ]

Отдельный Image уже предусмотрен: изображение вписывается в область высотой 300 dp без обрезки, ниже показывается подпись. Не добавляйте пути к отсутствующим файлам. Данные, изображения и оба OWL нужно переносить вместе. Никаких shell-команд или внешних пакетов в runtime нет; requires { pacman: [] } это отражает. Источник file читает данные через доступные лаунчеру файлы Linux; сетевых запросов нет.

## Проверка

Из родительской папки:

    owl-send 84-oma-another-features-app.owl refresh
    owl-send 85-oma-another-features.owl refresh
    owl-check 84-oma-another-features-app.owl
    owl-check 85-oma-another-features.owl

Откройте PNG, напечатанные owl-check. Проверяйте и список, и подробную карточку. Если каталог создавался уже после загрузки интерфейса, refresh перечитает его без ожидания файлового наблюдателя.

Для предпросмотра подробностей:

    owl-send 84-oma-another-features-app.owl set selected backup
    owl-check 84-oma-another-features-app.owl
    owl-send 84-oma-another-features-app.owl set selected '""'

Верните selected, query, category и onlySaved к обычным значениям после тестирования. Не перезаписывайте пользовательское избранное ради проверки.

Иконка приложения проверена через rsvg-convert в 192 и 48 px; инструмент предоставляется пакетом librsvg, установленным командой pacman -S --needed --noconfirm librsvg. Он не нужен для работы каталога.
