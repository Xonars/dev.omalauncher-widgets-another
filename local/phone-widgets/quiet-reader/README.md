# Тихая читалка

Отдельное OWL-приложение: `../quiet-reader.owl`. Эта папка — его исходники;
при переносе приложения копируйте файл OWL вместе с папкой.

Выберите EPUB, MOBI или TXT в списке папок и нажмите книгу. Долгое нажатие
на текст или Android «Назад» открывает меню. «Читать» возвращает к книге.
Три темы: День, Сепия, Ночь. Последняя книга и тема сохраняются отдельно. Место прокрутки сохраняется
при открытии меню; после полного закрытия приложения книга открывается с начала. Старый Reader не изменяется.

Текст передаётся один раз и показывается штатным ленивым списком OWL.
При прокрутке нет команд, ручного перемещения Canvas и подгрузки окон.
На экране создаются только видимые текстовые блоки.
Разбор EPUB/MOBI взят из встроенного пакета Reader, с отдельным кешем
`~/.cache/owl-quiet-reader`. TXT поддерживает UTF-8 и Windows-1251.
Защищённые DRM и книги только из картинок не поддерживаются.

(GPL-3.0-only). Новый интерфейс и main.py распространяются по MIT.
